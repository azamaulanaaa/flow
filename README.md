# workspace

Node + TypeScript project (ESM, Node >= 20).

## Scripts

```sh
npm install
npm run build   # compile src/ -> dist/
npm start       # run dist/index.js
npm run typecheck
npm run clean
```

## Layout

- `src/` – TypeScript sources (`rootDir`)
- `dist/` – compiled output (gitignored)
